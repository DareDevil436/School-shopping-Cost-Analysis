# School-shopping-Cost-Analysis
# 🛒 Practice Shopping List Analysis

This project contains a dataset comparing the shopping lists of multiple individuals across different retail stores. The dataset highlights price variations, quantity requirements, and total costs for each person, allowing for insights into purchasing behavior and cost optimization.

## 📊 Overview

The dataset includes details from:
- **Susan**
- **Tim**
- **Mr. Om Kumar**

Each person’s shopping list is analyzed across major retailers like:
- 🏬 **Wall Mart**
- 💵 **Dollar Trap**
- 🗂️ **Office Depot**

## 🧾 Dataset Details

| Feature | Description |
|----------|-------------|
| **Item List** | The items purchased (e.g., Ball Point Pens, Calculators, Notebooks) |
| **Susan’s Qty / Tim’s Qty** | Quantity of each item bought by each person |
| **Store Prices** | Cost of items at different stores (Wall Mart, Dollar Trap, Office Depot) |
| **Store Totals** | Total cost per person per store |
| **Comparison Columns** | Used to evaluate best value and spending efficiency |

## 💡 Insights

- Price differences across stores for the same item  
- Quantity variation by individual  
- Which store provides the best overall value  
- Spending comparison between Susan, Tim, and Mr. Om Kumar  

## 📈 Example Items
- Ball Point Pens — different quantities and store pricing  
- TI-35 Calculator — compared across stores  
- 100 Page Notebooks — analyzed for total cost and value  

## 🛠️ Tools & Techniques
- **Microsoft Excel / CSV** for data organization  
- **Pivot Tables** for total and per-store comparisons  
- **Conditional Formatting** to highlight lowest prices  
- **Data Cleaning** for column alignment and clarity  

## 🎯 Purpose
This practice dataset demonstrates data cleaning, comparison analysis, and price optimization using tabular data. It’s ideal for learning:
- Excel-based comparison analysis
- Data interpretation and visualization
- Practical use of multi-store datasets
